# JobFit 智能简历工坊 - 项目方案

## 1. 项目概述

**一句话定位**  
智能分析用户自身能力与目标岗位 JD（职位描述）的匹配度，自动生成针对性强的定制化简历，并给出能力提升建议。

**核心价值**
- 告别海投简历，提高面试邀约率
- 自动提取 JD 关键要求，量化匹配度
- 智能重写经历，突出岗位关键词
- 提示能力短板，指导学习方向

---

## 2. 项目要解决什么问题？

**核心问题**  
求职者海投简历效率低、匹配度差，导致面试邀约率低。

**具体痛点**
- 用同一份简历投递所有岗位，无法突出与每个 JD 的关联性
- 手动修改耗时费力，不知道应该突出什么、删减什么
- 不会使用 STAR 法则和量化成果，表述平淡
- 容易被 ATS（简历筛选系统）过滤
- 缺少客观匹配度评估，不清楚自己差距在哪里

**解决目标**  
通过 AI 分析用户自身条件与目标 JD 的差异，**自动生成一份针对性强、关键词匹配度高、表述专业的定制化简历**，同时给出能力差距提示。

## 3. 主要功能需求

| 优先级 | 功能模块 | 具体需求 |
|--------|----------|----------|
| P0（必须有） | 用户信息管理 | 手动填写/导入个人信息（教育、工作经历、技能、证书等），结构化存储。 |
| P0 | JD 解析器 | 粘贴 JD 文本，自动提取硬性要求（技能、年限、证书）、软性要求、职责关键词。 |
| P0 | 匹配度分析 | 对比用户信息与 JD，输出匹配度百分比、匹配项清单、缺失项清单、可优化项建议。 |
| P0 | 简历生成 | 根据匹配结果重组用户经历（措辞优化、关键词前置、量化引导），生成 PDF/Word。 |
| P1（重要） | 经历重写助手 | 基于 JD 关键词，为每条经历提供 2-3 种重写建议（STAR 格式），用户确认后应用。 |
| P1 | 多版本管理 | 为不同 JD 保存多个简历版本，随时切换编辑。 |
| P2（增强） | 简历导入解析 | 上传现有简历（PDF/Word）自动填充用户信息，减少手动录入。 |
| P2 | 岗位推荐/预警 | 匹配度过低时，提示用户学习/补充技能或调整求职方向。 |

## 4. 技术栈

### 前端
- React + TypeScript
- Tailwind CSS（或 Ant Design / shadcn/ui）
- 响应式设计，优先 PC Web 端

### 后端
- Python + FastAPI（方便集成 NLP 和 AI）

### NLP / AI
- JD 解析：SpaCy（实体识别）+ 自定义规则（年限、技能词库）
- 匹配度计算：TF-IDF + 余弦相似度（初期），后续升级为 BERT
- 文本生成：OpenAI API（GPT-3.5/4）或本地微调的小模型（如 ChatGLM）

### 数据库 & 存储
- PostgreSQL（存储用户信息、JD 历史、简历版本）
- Redis（缓存匹配结果）
- MinIO / 阿里云 OSS / AWS S3（存储原始简历和生成 PDF）

### PDF 生成
- WeasyPrint 或 Puppeteer（HTML 转 PDF）

### 部署
- Docker + Nginx
- 可选云平台：阿里云/腾讯云、Vercel + Railway
